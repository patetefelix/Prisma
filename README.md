# Prisma Cleaning — GitHub website

A portable, static website. No build tools or framework required.

## Preview

Serve this folder with any static server, or open index.html. Includes homepage and about.html.

## GitHub Pages

Unzip the package and upload its contents, including the assets folder, to the root of your GitHub repository. Keep index.html at the repository root, not inside an extra folder.

Upload the contents of this folder to the repository root. In Settings → Pages, publish the main branch / root folder. All page and asset links are relative and support a GitHub project URL. Add a custom domain later in Pages settings.

## Contact behavior

The quote form validates the required fields and opens a prefilled email to info@prisma.cleaning. It does not send or store submissions. A visitor must send the email from their email application. Phone and email links work directly. Connect a form provider later if direct website submission is preferred.

## Content and assets

Brand SVGs were supplied by the user. Work photographs were recovered from https://prisma-cleaning.webflow.io/ and optimized locally. Main site content was adapted from the supplied Webflow sites and company PDF, updated to reflect the user's description of an owner-operated business. The REI feedback is quoted from the newer Webflow site; it is labeled client feedback, not a Google review. No invented rating, customer count, or certification is shown.

The About page links to the supplied signed PDF URL. This link may expire; replace it with a permanent company PDF URL before launch. Verify the business phone, email, current services and service area with Diego before public launch. The missing D3 photographs can be added later.

Photo filenames, alt text, crops and gallery captions are editable in site-content.js. See PHOTO-GUIDE.md for the complete photo replacement instructions. Google Fonts is the only external styling dependency and has local font fallbacks.

Accessibility: semantic navigation, skip link, labeled form fields, keyboard-accessible gallery with Escape dismissal, reduced-motion support, mobile menu. Tested locally at desktop and mobile sizes.

## Latest design updates

Square SVG arrows; the original four-point star extracted from the supplied icon; gentle crystal glints, translucent light bands and a hover sheen. Reduced-motion preferences disable animation. The About page includes the owner-provided story of cleaning Restoration Hardware chandeliers and reflected crystal light. This describes the origin, without implying a current affiliation.

Social profiles are linked from https://linktr.ee/prisma.cleaning (checked September 11, 2026): Instagram, TikTok, Facebook, X, Threads and YouTube. Google remains available separately.

No repository or public deployment is created by this package. Choose main / root in GitHub Pages when you are ready to publish. No workflow or build command is required.
